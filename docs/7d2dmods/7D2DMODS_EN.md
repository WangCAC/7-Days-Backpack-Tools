# 7 Days to Die Custom Backpack Capacity Tool

**Version:** v1.4.0 · **Game:** V3.3 and later · **Platform:** Windows 64-bit · **Author:** WangCAC

## Description

Create a backpack mod that fits your playstyle. Choose character capacity, starting unencumbered slots, equipped backpack capacity, and layout, preview the result, then install or export your configuration.

This is a Windows mod generator. When you want a different setup, change the settings and generate it again, instead of searching for another fixed-capacity backpack mod.

![English main interface](https://raw.githubusercontent.com/WangCAC/7-Days-Backpack-Tools/v1.4.0/assets/screenshots/en/main.png)

*Example shown: 200 character slots, 50 starting unencumbered slots, and a large quality-6 backpack with 200 extra slots. Choose your own values to suit your game.*

## Main Features

- **Custom capacity:** Set character slots and starting unencumbered slots independently.
- **Equipped backpack support:** Set maximum equipped backpack capacity. Small, medium, and other quality levels adjust automatically using the large quality-6 backpack as the reference.
- **Adjustable layout:** Choose 8–20 slots per row and a backpack width from vanilla to widest. Installed and exported mods use your layout settings.
- **Auto fit:** Get a recommended row size and width with one click. Both sliders and the preview update together, and you can fine-tune the result afterward.
- **Live preview:** Choose a backpack type, quality, and Pack Mule rank to see available slots and encumbered areas before entering the game.
- **Two modes:** Game mode simulates the in-game appearance; Preview mode marks the extra slots provided by an equipped backpack.
- **Capacity details:** Compare Pack Mule bonuses and additional slots from all small, medium, and large backpack qualities.
- **Easy installation and sharing:** Install directly into the game's `Mods` folder or export a ZIP for backup, manual installation, or sharing.
- **Optional old-mod cleanup:** Remove other backpack mods generated by this tool when installing a new configuration.
- **Clear bilingual interface:** Simplified Chinese and English, with function icons and consistent button layouts.

## Installation Instructions

1. Close the game before installing or changing the generated mod.
2. Download and run the single-file EXE. For the portable ZIP, extract the entire folder and run `7DaysBackpackTools.exe`.
3. Set **Character slots**, **Starting free slots**, and **Max backpack slots**. Starting free slots cannot exceed character slots.
4. Adjust **Slots per row** and **Backpack width**, or click **Auto fit**. Check the preview and select equipment and Pack Mule options as needed.
5. Click **Scan for game**. If it is not found, click **Browse…** and select `7DaysToDie.exe` in the game directory.
6. Click **Install mod**. The tool installs the generated mod into the game's `Mods` folder, creating it if necessary.
7. Leave **Delete other mods generated by this tool to prevent conflicts** checked if you want to clean up older configurations, then click **OK**.
8. Start the game to use the new configuration.

![Game selection and installation](https://raw.githubusercontent.com/WangCAC/7-Days-Backpack-Tools/v1.4.0/assets/screenshots/en/installation.png)

![Installation confirmation and optional cleanup](https://raw.githubusercontent.com/WangCAC/7-Days-Backpack-Tools/v1.4.0/assets/screenshots/en/install-confirmation.png)

### Manual Installation or Sharing

Click **Export mod** to save a ZIP. Extract the mod folder into your game's `Mods` folder, keeping `ModInfo.xml` and `Config` inside the mod folder. Restart the game after changing the configuration.

## Requirements

- Windows 64-bit to run the tool.
- 7 Days to Die V3.3 or later.
- No additional mods are required to generate the backpack mod.
- Back up your save before changing capacity. Remove excess items before reducing the slot count.
- Other mods that change backpack capacity, encumbrance, or the same inventory interface may conflict. Use one compatible backpack setup at a time.

**Default settings:** 48 character slots, 32 starting unencumbered slots, 48 maximum equipped backpack slots, 8 slots per row, and vanilla width.
