# Changelog

## v1.4.0 (2026-10-08)

- **New backpack layout settings**: Adjust slots per row from 8 to 20 and backpack width from vanilla to widest. Both installed and exported mods use these settings.
- **New “Auto fit” button**: Automatically recommends slots per row and backpack width based on the current capacity, updating both sliders and the preview to reduce manual adjustments.
- **Improved backpack width preview**: Clearly see the size difference between backpack widths. The entire backpack window remains visible even at the widest setting, making it easier to choose a suitable layout in advance.
- **Improved button layout**: Buttons now share consistent column widths and alignment, with adjusted heights and spacing to leave more room at the bottom.
- **New function icons**: Button icons make functions easier to recognize, and English button text fits better.
- **Updated defaults and labels**: The defaults are 48 character slots, 32 starting unencumbered slots, 48 maximum equipped backpack slots, 8 slots per row, and vanilla width. “Large backpack · L6” is now “Max backpack slots,” and “Maximum backpack UI width” is now “Backpack width.”

## v1.3.0 (2026-10-03)

- **Customize equipped backpack capacity**: You can set the capacity of a large quality-6 backpack. The tool adjusts small, medium, and other quality levels together to suit your playstyle.
- **Preview backpack capacity changes**: Choose a backpack type, quality, and Pack Mule rank to see how many slots are unencumbered or still encumbered, without repeatedly entering the game to try settings.
- **Two ways to preview backpack capacity**: Game mode simulates how your backpack looks in the game. Preview mode uses markers to clearly show the extra slots provided by an equipped backpack.
- **New backpack capacity details window**: Compare Pack Mule bonuses and the additional slots provided by every quality of small, medium, and large backpacks in one place.
- **Fixed differences between the preview and the game**: Available slots and encumbered areas now display more accurately when you equip or remove a backpack, helping you decide whether your setup has enough space.
- **Improved large death-backpack display**: Scroll through items when retrieving your dropped backpack, reducing problems with oversized inventory windows getting in the way of looting.
- **Fewer conflicts with old configurations**: After installing a new setup, you can remove other backpack mods generated by this tool, making capacity changes easier.
- **A cleaner interface**: A blue color scheme, sharper graphics, and improved buttons, inputs, and messages. Chinese and English now use the same layout.
- **Vanilla starting values**: Defaults are now 40 character slots, 32 starting unencumbered slots, and 48 slots for a large quality-6 backpack, so you can start from familiar settings.
- **A lighter single-file app**: A smaller download and faster subsequent launches make everyday backpack adjustments more convenient.

## v1.2.0 (2026-10-03)

- Added configurable large quality-6 backpack capacity, with all small, medium, and large backpack qualities scaled using vanilla ratios.
- Moved Pack Mule values into a details dialog, alongside capacity data for all 18 backpack variants.
- Added interactive previews for the character inventory, equipped backpacks, and Pack Mule, with selectable backpack type, quality, and skill rank.
- Marked backpack slots with softly pulsing backpack icons: red when encumbered and green when unlocked.
- Added a softly glowing red pixel prohibition icon when character preview is disabled.
- Adjusted large death-backpack layouts to use bounded viewports and scrolling for the full contents.
- Updated Chinese and English UI text and fixed preview selections after language changes and native control style interference.

## v1.0.5 (2026-09-30)

- Added support for physical backpacks in newer game versions, so they can increase inventory capacity.
- Testing showed that clothing, mods, and other items that increase carrying capacity in the current game version did not add usable slots as expected. The tool now reserves extra slots for these bonuses.
- Limited generated backpacks to 20 slots per row for a clearer layout.
- Added pop-up notifications for tool actions to improve usability.
